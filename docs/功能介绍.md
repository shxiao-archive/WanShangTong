# 功能介绍

## 项目定位

万州商户通是面向万州中小商户的数字化经营助手 MVP。平台将商户入驻、店铺档案、经营数据、规则画像、资源推荐和服务跟进集中在同一个系统中。

平台的目标是让商户更容易地看懂经营数据、明确数字化需求，同时让运营人员能够统一处理入驻审核、资源维护和服务申请。

## 用户角色

### 商户用户

商户用户可以注册并申请入驻，审核通过后维护自己的店铺和经营数据，查看经营分析、商户画像与资源推荐，并提交数字化服务申请。

### 运营管理人员

运营人员负责审核商户入驻资料、查看商户档案与经营情况、维护推荐资源，以及跟进商户提交的服务申请。

## 主要功能

### 1. 账号与入口隔离

- 支持商户账号和运营账号登录。
- 支持创建试运营账号，运营账号注册需使用邀请码。
- 支持首次登录强制改密码、退出登录和账号状态管理。
- 生产环境可通过 `merchant.*` 和 `admin.*` 子域名区分商户端与管理端。

### 2. 商户入驻

新商户通过五步引导完成入驻：

1. 填写企业或个体工商户的主体资质。
2. 填写店铺名称、行业、地址和经营规模。
3. 填写联系人与授权信息。
4. 根据行业上传营业执照、许可证或备案材料。
5. 预览资料并提交审核。

运营人员可查看申请和资质材料，选择审核通过或要求补充资料。通过后，系统创建商户档案并开放工作台。

### 3. 首页概览

- 商户端展示门店经营摘要、数字化画像和常用功能入口。
- 管理端展示商户数量、待跟进申请、行业分布和热门需求。

### 4. 店铺档案

商户可维护店铺基本资料、营业时间、经营规模、网络环境、数字化需求，以及主要商品或服务。商品支持名称、分类、价格和图片。

运营人员可搜索、筛选并查看已入驻商户，但商户业务数据的写入权限仍归属对应商户。

### 5. 经营数据与分析

商户可手工录入或通过 Excel 导入每日的访客数、订单数、营业额、订单来源、评分和高峰时段。系统提供：

- 营收与客流趋势。
- 订单来源占比。
- 营业高峰时段。
- 客单价、累计收入等指标。
- Excel 模板下载、导入校验和数据导出。

### 6. 可解释商户画像

系统根据商户档案和经营数据，生成经营规模、数字化程度、网络状况、所属行业和核心需求等结果。所有结论均由透明业务规则生成，并展示判断依据。

### 7. 资源推荐与管理

平台结合商户行业、网络环境和实际需求，匹配网络、数字化、安防、营销等服务资源。推荐结果包含匹配分数、推荐理由、参考价格和包含服务。

运营人员可新增、编辑、启用或停用资源，并维护其适配行业和需求标签。

### 8. 服务申请与跟进

商户可从推荐页提交服务申请，并在“我的申请”中查看当前状态、跟进备注和完整时间线。

运营人员可记录沟通结果，并将申请从待处理推进至办理中、已完成或已取消。

### 9. 通知与待办

平台将入驻审核和服务申请的重要变化汇总为站内通知。用户可按业务类型筛选、标记已读，并直接跳转到对应业务详情。管理端还提供待审入驻和待跟进服务的集中待办列表。

## 典型业务流程

### 商户入驻

注册账号 → 填写入驻资料 → 上传资质文件 → 提交审核 → 运营审核 → 创建商户档案 → 进入商户工作台。

### 经营分析

完善店铺档案 → 录入或导入经营数据 → 汇总经营指标 → 生成图表 → 生成可解释画像。

### 数字化服务

系统匹配资源 → 商户查看推荐理由 → 提交申请 → 运营沟通办理 → 记录跟进过程 → 完成或取消申请。

## MVP 边界

- 不包含支付、短信、外卖平台、短视频平台或运营商生产系统接入。
- 商户画像与资源推荐使用可解释规则，不使用机器学习或大模型。
- 仓库内的名称、地址、电话和经营数据均为虚构演示数据。
- 推荐结果和参考价格仅用于演示，实际服务与价格需由运营方确认。
