# 开发指南

## 环境要求

- Python 3.12
- Node.js 22 与 npm
- 本地开发可直接使用 SQLite，不必启动 MySQL。
- Docker 与 Docker Compose 用于容器化验证和生产部署。

## 快速启动

### 1. 启动后端

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
```

编辑 `backend/.env`，至少将以下占位值替换为仅用于本地开发的值：

- `JWT_SECRET`
- `CREDENTIAL_ENCRYPTION_KEY`
- `DEMO_OPERATOR_PASSWORD`
- `DEMO_MERCHANT_PASSWORD`

首次启动前执行数据库迁移：

```bash
python -m alembic upgrade head
uvicorn app.main:app --reload
```

后端默认运行在 `http://127.0.0.1:8000`：

- Swagger UI：`http://127.0.0.1:8000/api/docs`
- OpenAPI JSON：`http://127.0.0.1:8000/api/openapi.json`
- 健康检查：`http://127.0.0.1:8000/api/v1/health`

开发模式启动时会对缺少的表执行 `create_all`，并在空数据库中写入虚构演示数据。仍建议显式执行 Alembic，使本地结构与生产迁移链保持一致。

### 2. 启动前端

另开一个终端：

```bash
cd frontend
npm ci
npm run dev
```

访问 `http://localhost:5173`。Vite 会将 `/api` 请求代理到 `http://127.0.0.1:8000`。本地主机名不锁定入口角色，可在同一入口测试商户账号和运营账号。

## 常用开发命令

### 后端

```bash
cd backend

# 运行全部测试
pytest -q

# 运行单个测试文件
pytest -q tests/test_api.py

# 检查当前迁移版本
python -m alembic current

# 升级到最新迁移
python -m alembic upgrade head

# 对已启动的 API 执行冒烟验证
python tests/smoke_live.py http://127.0.0.1:8000
```

### 前端

```bash
cd frontend

# TypeScript/Vue 类型检查
npm run lint

# 生产构建
npm run build

# Playwright 端到端测试，需先准备可访问的测试系统
npm run test:e2e
```

如果端到端测试不使用默认地址，可指定：

```bash
PLAYWRIGHT_BASE_URL=http://127.0.0.1:8080 npm run test:e2e
```

## 数据库变更

修改 `backend/app/models.py` 后，必须同时提供 Alembic 迁移，不要依赖开发环境的自动建表。

```bash
cd backend
python -m alembic revision --autogenerate -m "describe change"
python -m alembic upgrade head
pytest -q tests/test_migration.py
```

生成迁移后应人工检查：

- `revision` 和 `down_revision` 是否连接当前迁移链。
- 是否会意外删除列、索引或数据。
- SQLite 和 MySQL 的字段类型是否都可用。
- `downgrade()` 的数据丢失风险是否可接受。

## API 开发约定

- 业务接口使用 `/api/v1` 前缀。
- JSON 响应使用 `{ code, message, data }` 结构。
- 输入校验放在 Pydantic Schema，权限检查放在后端依赖或业务路由，不只依赖前端隐藏按钮。
- 商户资源必须检查当前账号与 `merchant_id` 的归属关系。
- 修改关键状态时应写入审计记录，并在需要时生成通知。
- 新增接口时应补充接口测试，并更新 [API 概览](./API概览.md)。

## 前端开发约定

- 页面通过 `frontend/src/services/api.ts` 的 Axios 实例访问 API。
- 响应拦截器已解包 `data`，页面中直接使用业务数据。
- 角色专属页面需在路由 `meta` 中声明权限，但后端仍必须独立校验。
- 新增主要用户流程时，应补充桌面端和移动端 Playwright 覆盖。

## 敏感数据与本地文件

不要提交以下内容：

- `.env` 和真实密钥。
- SQLite 数据库、上传文件、备份和测试产物。
- 真实商户名称、联系方式、资质文件或经营数据。
- 生产域名、服务器地址和云存储配置。
