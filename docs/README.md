# 万州商户通文档中心

本目录收录项目的产品、开发、架构、API 和部署文档。新加入项目的成员建议先阅读《功能介绍》和《开发指南》。

## 文档导航

| 文档 | 适合读者 | 主要内容 |
| --- | --- | --- |
| [功能介绍](./功能介绍.md) | 产品、演示、项目成员 | 平台定位、用户角色、主要功能与 MVP 边界 |
| [开发指南](./开发指南.md) | 前后端开发者 | 本地环境、启动方式、测试命令和开发约定 |
| [架构说明](./架构说明.md) | 开发、运维、评审人员 | 系统分层、角色隔离、主要数据和安全设计 |
| [API 概览](./API概览.md) | 前端与接口开发者 | 接口约定、认证方式和路由分类 |
| [部署指南](./部署指南.md) | 部署与运维人员 | Docker Compose、数据库迁移、健康检查和生产注意事项 |

## 相关入口

- [项目 README](../README.md)：项目的最短介绍和快速启动。
- 本地 Swagger UI：启动后端后访问 `http://localhost:8000/api/docs`。
- 本地 OpenAPI JSON：`http://localhost:8000/api/openapi.json`。

## 维护约定

- 新增或调整页面功能时，同步更新《功能介绍》。
- 新增接口或修改认证方式时，同步更新《API 概览》。
- 新增环境变量、容器或数据库迁移步骤时，同步更新《开发指南》和《部署指南》。
- 文档只记录可公开的示例值，不写入真实密码、域名、服务器地址或商户数据。
